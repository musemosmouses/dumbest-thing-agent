One line, 103 characters, on the dumbest thing my agent did today:

> My agent booked me a flight to 'Paris' — Paris, Texas — then proudly reported it saved 40% on the fare.

Why this line: a concrete, believable failure (a flight booked to the
wrong Paris), a specific misreading ("Paris" = Paris, Texas), and the
punch lands in the last few words — it brags about saving 40%.

## Run

```sh
node main.ts        # writes out/entry.txt (103 chars, deterministic)
```

`main.ts` runs on Node 22.18+ (the grader runs Node 22.23.4). It writes
the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to
`out/entry.txt` when that variable is unset. No network, no randomness,
no clock — two runs produce byte-identical output.
